### 1.2 无图评估与运动

```text
scripts/far_waypoint_shadow.py
scripts/far_single_waypoint_trial.py
scripts/far_waypoint_follower_trial.py
```

用途：

- `far_waypoint_shadow.py`：只读坐标、方向和距离核对，不发布速度。
- `far_single_waypoint_trial.py`：短距离单航点受控试验。
- `far_waypoint_follower_trial.py`：当前主线；支持 2D Goal 转换、FAR 航点流、运控反馈、局部 costmap、碰撞扫掠、局部 A*、路径显示和到达判据。

主脚本当前关键默认/功能：

- 最终目标和局部航点范围可分别限制，最大可配置到 20 m。
- 线速度/转弯/弧线速度实验值约 0.4 m/s。
- 角速度上限约 0.6 rad/s，目标转弯半径 0.8 m。
- GO 前缓存航点，GO 后刷新安全反馈，减少阻塞输入造成的“缺少新 waypoint”。
- FAR 到达信号必须与里程计目标距离共同满足，避免 FAR 提前完成。
- 发布 `/my_nav/local_avoid_path` 供 RViz 显示。

说明文档：

```text
docs/implementation_notes/navigation_range_trial_README.md
docs/implementation_notes/turn_trial_README.md
docs/implementation_notes/2026-10-20_转弯半径与GO航点修复说明.md
docs/implementation_notes/2026-10-20_FAR局部代价地图避障接入.md
```

## 6. 修改规范

1. **厂家驱动不改**：消息适配由独立 converter 完成。
2. **frame 私有化**：FAST-LIO2 和无图导航只能使用 `fastlio_*`、`my_nav_*`，禁止复用 HRIC `map/base_link/body` 而不做严格 TF 设计。
3. **topic 命名分层**：原始 `/livox/*`、定位 `/fastlio2/*`、适配 `/my_nav/*`、FAR 实验 `/far_eval/*`、运控 `/hric/*`。
4. **参数显式化**：速度、距离、超时、足迹、代价阈值都应有 CLI/YAML 来源，不能散落为魔数。
5. **单一速度所有者**：运动前检查 `/hric/robot/cmd_vel --verbose`；脚本运行期间禁止第二个自主控制器加入。
6. **先只读后运动**：shadow → 单航点 → 短路线 → 障碍场景 → 长距离。
7. **来源可追溯**：每次部署保存 `git rev-parse HEAD`、`git diff`、`sha256sum`、构建日志。
8. **不覆盖现场版本**：先收集和比对，再部署；严禁用聊天中重构的片段直接覆盖机器人唯一源码。
9. **构建后验收安装空间**：检查 `ros2 pkg prefix`、已安装 YAML 和运行进程参数。
10. **运动逻辑必须有测试**：至少覆盖角度归一化、速度/曲率、航点新鲜度、FAR 提前到达、costmap 索引、膨胀/扫掠、A* 无路/有路和停机路径。
