# FAR 无图导航控制脚本修复说明

已修改 `far_waypoint_follower_trial.py`：

- 直线速度、弧线速度和大角度行走转向速度默认均为 `0.4 m/s`。
- 新增 `--turn-radius`，默认目标转弯半径为 `0.8 m`。
- 最大角速度默认改为 `0.6 rad/s`。当 `v=0.4 m/s`、目标半径为 `0.8 m` 时，转弯命令约为 `w=0.5 rad/s`。
- GO 后不再要求 FAR 必须重新发布一帧航点。只要缓存航点属于当前目标，且人工确认期间机器人位姿没有明显变化，就允许启动。
- 启动后给缓存航点保留 5 秒引导窗口；如果机器人运动后 FAR 仍未恢复航点更新，控制器会停止。

## 上传到机器人

在 Windows PowerShell 执行：

```powershell
scp scripts/far_waypoint_follower_trial.py \
  nvidia@<ROBOT_IP>:/home/nvidia/hric_tools/far_waypoint_follower_turntest.py
```

## 机器人端预检

```bash
source /home/nvidia/hric_tools/hric_env.sh
source ~/fastlio2_ws/install/setup.bash
source ~/tiangong_nav_ws/install/setup.bash
source ~/robot_motion_control/install/setup.bash
source ~/far_planner_eval_ws/far_planner/install/setup.bash
unset ROS_DOMAIN_ID

python3 /home/nvidia/hric_tools/far_waypoint_follower_turntest.py \
  --max-route-distance 5.0 \
  --max-travel 2.0 \
  --max-linear-speed 0.4 \
  --turn-linear-speed 0.4 \
  --arc-linear-speed 0.4 \
  --max-angular-speed 0.6 \
  --turn-radius 0.8 \
  --timeout 30
```

## 运动测试

确认预检打印了“目标转弯半径 0.80 m”后，再执行：

```bash
python3 /home/nvidia/hric_tools/far_waypoint_follower_turntest.py \
  --execute \
  --max-route-distance 5.0 \
  --max-travel 2.0 \
  --max-linear-speed 0.4 \
  --turn-linear-speed 0.4 \
  --arc-linear-speed 0.4 \
  --max-angular-speed 0.6 \
  --turn-radius 0.8 \
  --timeout 30
```

如仍觉得半径偏大，可把 `--turn-radius` 改为 `0.7`；此时理论角速度约为 `0.57 rad/s`。不要同时把 `--max-angular-speed` 设得低于这个值，否则角速度会被限幅，实际半径仍会变大。
