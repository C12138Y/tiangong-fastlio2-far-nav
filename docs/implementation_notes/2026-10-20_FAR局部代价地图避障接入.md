# FAR 无图导航：局部代价地图与避障门控

## 已接入的控制链

```text
/fastlio2/body_cloud
        ↓
/my_nav/local_costmap（Nav2 VoxelLayer）
        ↓
/my_nav/costmap（nav_msgs/OccupancyGrid）
        ↓
far_waypoint_follower_trial.py 局部 A* + 碰撞门控
        ↓
安全时跟随局部绕障点；无路时发布零速并等待地图/FAR更新
```

FAR 负责全局路线和航点更新。跟随器在局部 Costmap 上运行 8 邻域 A*；直达控制段有障碍时，从 A* 路径选取前方 `0.8 m` 的局部跟踪点。每条实际速度命令还会检查未来 `1.2 m` 的弧线扫掠区域。代价大于等于 `65`、未知区域、地图过期或地图断流都会禁止继续行走。障碍持续 `5 s` 且局部 A* 与 FAR 都没有给出安全路径时，任务退出并持续发送零速 `2 s`。

局部跟踪点方向与机器人航向相差超过 `10°` 时，先以 `v=0`、`|w|=0.5 rad/s` 原地对准，避免用大半径弧线切过障碍角点。局部 A* 路径同时发布到 `/my_nav/local_avoid_path`。

ros2 lifecycle get /my_nav/local_costmap

ros2 lifecycle set /my_nav/local_costmap activate
ros2 lifecycle get /my_nav/local_costmap

ros2 topic info /my_nav/costmap --verbose
timeout 10 ros2 topic echo /my_nav/costmap --once --field header
timeout 10 ros2 topic echo /my_nav/costmap --once --field info
timeout 10 ros2 topic hz /my_nav/costmap

最终生命周期必须为 `active`；`/my_nav/costmap` 必须持续发布且 `frame_id` 为 `fastlio_odom`。如果节点已经是 `active`，不要再次执行 `configure/activate`。

## 运动验证

先在 RViz 添加 `Map`，Topic 选择 `/my_nav/costmap`，确认实体障碍在地图中显示；再添加 `Path`，Topic 选择 `/my_nav/local_avoid_path`，检查本地绕障路径。然后仅在现场条件满足时，在上述命令中加入 `--execute`。

第一次验证建议把一个不会移动的障碍放在机器人前方但保持停车距离，观察终端是否打印：

```text
代价地图停车：前方扫掠足迹命中代价 ...；等待局部 A* 或 FAR 给出安全路径。
```

若 A* 找到绕行路径，终端会打印 `控制阶段：局部A*绕障/...`；若没有安全路径，则必须看到机器人停止。移除障碍后，如果地图完成清除，脚本会恢复运动。

不要用 `--allow-unknown-costmap` 作为首次运行参数。若出现 `代价 -1`，先确认点云、射线清除和 costmap 配置；该参数会允许机器人进入未观测区域。
