# 天工 3.0 FAST-LIO2 + FAR Planner 完整部署与代码归档

整理日期：2026-10-20  
适用平台：天工 3.0、NVIDIA ARM64、Ubuntu 24.04、ROS 2 Jazzy  
资料范围：`部署fastlio2`、`部署fastlio2 (2)`、`部署fastlio2 (3)` 三个对话，以及本工作区已有交接文档、脚本和测试。

## 1. 当前技术路线

```text
/livox/lidar (PointCloud2) ──> pc2_to_custom ──> /fastlio2/livox_custom
/livox/imu ─────────────────────────────────────┘
                                                   │
                                                   v
                                              FAST-LIO2
                                                   │
                          ┌────────────────────────┼──────────────────────┐
                          v                        v                      v
                 /fastlio2/lio_odom       /fastlio2/world_cloud  /fastlio2/body_cloud
                          │                        │                      │
                          v                        │                      v
               fastlio_nav_adapter                │             Nav2 局部代价地图
                          │                        │                      │
                    /my_nav/odom                   v                      v
                          │             terrain_analysis(_ext)     /my_nav/costmap
                          │                        │                      │
                          └───────────────> FAR Planner <────────────────┘
                                                   │
                          /far_eval/way_point + /viz_path_topic
                                                   │
                                                   v
                             far_waypoint_follower_trial.py
                                                   │
                                      /hric/robot/cmd_vel
                                                   │
                                      hric_topic_bridge / 运控
```

这是一条“无 HRIC 静态地图”的实验链路：FAST-LIO2 提供实时里程计与点云，FAR 负责图搜索和航点，独立局部代价地图负责近场碰撞检查与局部 A*，实验跟踪器直接向运控速度接口发命令。它不等同于 HRIC 原生的加载地图、重定位、`StartNav` 导航链路。

## 2. 已经完成并现场验证的部分

- Livox MID360 的 ROS 2 驱动数据正常：`/livox/lidar` 为 `PointCloud2`，`/livox/imu` 持续发布。
- FAST-LIO2 已在 Jazzy/ARM64 上完成源码编译和实时运行。
- 已用独立转换节点解决 FAST-LIO2 端口需要 `CustomMsg`、厂家驱动输出 `PointCloud2` 的不匹配。
- FAST-LIO2 使用独立坐标系 `fastlio_odom -> fastlio_body`，避免与 HRIC 的 `base_link/body` TF 冲突。
- `/my_nav/odom`、terrain analysis、FAR Planner 的实时链路已打通。
- FAR 可以接收 RViz 目标、更新 V-Graph、发布 `/far_eval/way_point` 和 `/viz_path_topic`。
- RViz `2D Goal Pose` 的 `/goal_pose` 已由跟踪脚本转换为 FAR 所需的 `/far_eval/goal_point`。
- 无图速度控制已验证：在空旷区域，机器人能够直行和转向。
- 已发现平台存在低速死区：过低的线速度/角速度只会轻微晃动或完全不走；当前实验参数采用约 `0.4 m/s` 线速度和最高 `0.6 rad/s` 角速度。
- 已接入 `/my_nav/costmap`、扫掠足迹碰撞检查和局部 8 邻域 A*；预检能够在直线路径受阻时生成绕行栅格路径。

## 3. 尚未闭环的问题

- 低矮柜体等障碍仍可能未进入 FAR 障碍模型，也可能被局部 voxel costmap 的高度窗口过滤。
- FAR 当前可能把远目标直接作为航点，`/viz_path_topic` 只有起点和终点；这不是可靠避障路径。
- 已看到“预检能生成局部 A*，执行时仍因直达扫掠受阻而停车”的现象，说明局部 A* 到控制器的实际接管还需继续验证。
- 机器人尺寸、足迹半径、雷达外参、地形高度阈值仍未用实测标定。
- `/hric/robot/cmd_vel` 的多发布者仲裁仍需工程化。实验前必须确保没有 `hric_path_tracker` 与自定义跟踪器同时发速度。
- 尚未完成带真实障碍的长距离全流程绕行验收。
