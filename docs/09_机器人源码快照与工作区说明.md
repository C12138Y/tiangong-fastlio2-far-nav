## 三个工作区是否还需要

机器人上仍然需要：

```text
~/fastlio2_ws
~/tiangong_nav_ws
~/far_planner_eval_ws
```

原因：

- `fastlio2_ws` 提供 converter 和 FAST-LIO2 可执行文件。
- `tiangong_nav_ws` 提供 `/my_nav/odom`、TF、全局地图构建器和 local costmap。
- `far_planner_eval_ws` 提供 terrain analysis 和 FAR Planner。

不能因为已经复制源码快照，就删除机器人上的工作区；其 `install/` 正被启动脚本 source，删除会让现有链路无法启动。

## 重新创建源码工作区

在一台不存在同名源码目录的机器人或开发机上：

```bash
chmod +x scripts/bootstrap_ros_sources.sh
scripts/bootstrap_ros_sources.sh
```

该脚本会克隆固定上游 commit、应用补丁、复制 converter，并安装 adapter 源码包。它不会覆盖已有目录，也不会执行 colcon 构建。Sophus 安装和构建步骤继续按 `docs/01`、`docs/02` 执行。
