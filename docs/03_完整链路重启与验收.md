# 完整链路重启与验收

## 1. 启动前总检查

所有终端使用相同环境顺序：

```bash
source /home/nvidia/hric_tools/hric_env.sh
source ~/fastlio2_ws/install/setup.bash
source ~/tiangong_nav_ws/install/setup.bash
source ~/far_planner_eval_ws/cmu_dev_jazzy/install/setup.bash
source ~/far_planner_eval_ws/far_planner/install/setup.bash
unset ROS_DOMAIN_ID
```

检查原始传感器：

```bash
ros2 topic info /livox/lidar
ros2 topic info /livox/imu
timeout 8 ros2 topic hz /livox/lidar
timeout 8 ros2 topic hz /livox/imu
```

检查是否残留旧进程和重复节点：

```bash
ps -eo pid,ppid,stat,args | grep -E \
  '[p]c2_to_custom|[l]io_launch.py|[l]io_node|[f]astlio_nav_adapter|[t]errainAnalysis|[f]ar_planner|[h]ric_path_tracker'
ros2 node list --no-daemon | sort
```

## 5. RViz 设置

```bash
source /home/nvidia/hric_tools/hric_env.sh
source ~/fastlio2_ws/install/setup.bash
source ~/far_planner_eval_ws/far_planner/install/setup.bash
unset ROS_DOMAIN_ID

rviz2 -d /home/nvidia/fastlio2_ws/install/fastlio2/share/fastlio2/rviz/fastlio2.rviz
```

核心设置：

- Fixed Frame：`fastlio_odom`
- Publish Point Topic：`/far_eval/goal_point`
- 2D Goal Pose Topic：`/goal_pose`
- FAR 路径：添加 `Marker`，Topic `/viz_path_topic`
- FAR 图：添加 `MarkerArray`，Topic `/viz_graph_topic`
- 当前帧点云：`/fastlio2/world_cloud` 或 `/fastlio2/body_cloud`
- 障碍调试：`/FAR_obs_debug`
- 局部代价地图：添加 `Map`，Topic `/my_nav/costmap`
- 局部 A*：添加 `Path`，Topic `/my_nav/local_avoid_path`

取消某个 display 的勾选只会隐藏显示，不会停止对应 ROS 节点。Marker/MarkerArray 类型选错时即使 topic 正常也不会显示。

## 7. 运动前检查

确认运控处于 SWR：

```bash
timeout 6 ros2 topic echo /hric/robot/rl_state --once
```

确认速度端点：

```bash
ros2 topic info /hric/robot/cmd_vel --verbose
```

正常实验状态应只有遥控桥作为既有发布者。若看到 `hric_path_tracker`，不要启动自定义跟踪器。先停止对应 launch 及其子进程，再等待 DDS 图刷新；必要时重启 ROS daemon。不能只杀 launch 父进程，因为子节点可能成为 PPID 1 的孤儿继续发布。

## 8. 推荐运动测试顺序

### 8.1 单航点短距离试验

```bash
python3 /home/nvidia/hric_tools/far_single_waypoint_trial.py --execute \
  --max-travel 1.0 \
  --max-waypoint-distance 1.5 \
  --max-linear-speed 0.4
```

### 8.2 FAR 航点流跟踪

先预检：

```bash
python3 /home/nvidia/hric_tools/far_waypoint_follower_trial.py \
  --max-goal-distance 20.0 \
  --max-route-distance 20.0 \
  --max-travel 2.0 \
  --max-linear-speed 0.4 \
  --turn-linear-speed 0.4 \
  --arc-linear-speed 0.4 \
  --max-angular-speed 0.6 \
  --turn-radius 0.8 \
  --planner-timeout 30 \
  --timeout 60
```

执行版：

```bash
python3 /home/nvidia/hric_tools/far_waypoint_follower_trial.py \
  --execute \
  --max-goal-distance 20.0 \
  --max-route-distance 20.0 \
  --max-travel 2.0 \
  --max-linear-speed 0.4 \
  --turn-linear-speed 0.4 \
  --arc-linear-speed 0.4 \
  --max-angular-speed 0.6 \
  --turn-radius 0.8 \
  --costmap-lookahead 1.2 \
  --costmap-footprint-radius 0.45 \
  --costmap-threshold 65 \
  --costmap-max-age 2.0 \
  --costmap-block-timeout 5.0 \
  --planner-timeout 30 \
  --timeout 60
```

重要：20 m 是软件允许接受的最终目标/航点范围，不代表机器人一次可安全行走 20 m。`--max-travel 2.0` 仍限制本轮累计移动，长距离必须分段验收。

## 9. 停止顺序

按 Ctrl+C 停止运动脚本后，确认其已持续发送零速。再停止 FAR、terrain、adapter、FAST-LIO2 和转换器。使用管理脚本时：

```bash
/home/nvidia/hric_tools/far_stack_stop.sh
/home/nvidia/hric_tools/far_stack_status.sh
```

最后检查：

```bash
ps -eo pid,args | grep -E \
  '[p]c2_to_custom|[l]io_node|[f]astlio_nav_adapter|[t]errainAnalysis|[f]ar_planner'
```
